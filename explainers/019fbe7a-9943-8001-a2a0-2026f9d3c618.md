RRS stands for Rocket Reader SomaCoSF and also Reverse RSS. It is a system that gives every file a permanent, speed-readable explanation identified by a UUIDv8. Classic RSS pushes content to the reader. RRS lets the file itself invite the reader into its own explanation on demand. The one-line header in a source file acts as a QR code. The UUIDv8 is the permanent address. The Rocket Reader is the delivery surface that flashes words one at a time with Optimal Recognition Point highlighting so a developer can absorb the essence of a module in under ninety seconds at three hundred words per minute. Every explanation is committed under the explainers directory with rich front matter that records the source path, model used, tags, and word count. The design deliberately freezes only the identity format, the header contract, the flowing-prose body, and the URL resolver. Everything else remains open so future models and agents can participate without breaking existing links. This repository dogfoods the system: the vision document you are reading is itself explained by an RRS entry. That recursive property is the product working on itself and is the foundation for future-retro-recursiveness — planning the interface that unknown future tools will still be able to speak.
