# Future-Retro-Recursiveness

We design for a world we cannot fully see.

## Contracts we freeze

1. UUIDv8 as stable identity
2. One-line header as discovery
3. Flowing prose body as consumption format
4. Git + static files as persistence
5. URL resolver as the only required runtime

Any system that can resolve a URL and present words can become an RRS client. Any system that can write a comment and call HTTP can become a producer. That minimal interface survives model and platform churn.
